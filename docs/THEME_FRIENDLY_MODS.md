# Theme-Friendly Companion Mods

These mods keep the platformer feel intact and mostly sit in the background (performance, sound, UI). Avoid mods that add magic/tech/cosmic clutter or break the clean course-read.

## Performance & Stability

- **Sodium** — modern OpenGL rendering; the biggest FPS win for dense courses.
- **Lithium** / **Canary** — optimizes tick logic without changing behavior.
- **FerriteCore** — reduces memory pressure, especially with many block states.
- **Starlight** — faster light propagation; courses with beacons/gates look cleaner.
- **Entity Culling** / **More Culling** — hides off-screen mobs and blocks.
- **Dynamic FPS** — drops render rate when the game is unfocused (great while tabbing out).
- **Clumps** — groups XP orbs; also works for glint drops if they ever use XP.

## Audio & Atmosphere

- **Sound Physics Remastered** — reverb inside tunnels/pipes; no copyrighted music.
- **Presence Footsteps** — footstep variation that reads as "platformer" without adding content.
- **AmbientSounds** — subtle wind/cave ambience; keep it low so it does not drown course music.

## UI / QoL

- **AppleSkin** — hunger/saturation overlay; courses might drain sprint energy.
- **Controlling** — keybind search because F/G and movement modifiers add up.
- **Mouse Tweaks** — inventory drag sorting; minor.
- **Xaero's Minimap (square, no waypoints)** or **JourneyMap** — only if courses are large enough to get lost; keep it subtle.
- **BetterF3** — cleaner debug overlay for testing the rail/drift values.

## Visuals

- **Wavey Capes** — small flair, not distracting.
- **Customizable Player Models** — optional Mario-style costumes; only client-side.
- **Distant Horizons** — keep off; it changes the silhouette of courses.

## Mods to Avoid

- **Large tech/magic mods** (Create, Mekanism, etc.) — clash with the clean platformer theme.
- **Shader packs that add heavy fog/bloom** — can hide the 2.5D silhouette and rail.
- **Minimap mods with 3D waypoints / boss bars** — break the authored camera read.
- **Physics / destruction mods** — can break authored course geometry.
